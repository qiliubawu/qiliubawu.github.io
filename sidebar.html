弹跳侧边栏

一个带圆点指示器的锚点侧边栏。选中项切换时，圆点不会直线平移，而是沿一段弧线 弹跳滑行到新位置；跨度越大，弧度越平缓。点击左侧菜单即可感受。

提示 · 点击左侧任意菜单项，观察圆点的弹跳轨迹

概览

组件由三部分组成：分组标题、可点击菜单项， 以及一枚绝对定位的圆点指示器。菜单数据以数组描述， 每一项可以是纯字符串、带链接的对象，或标记为分组标题的对象。

圆点的纵向位置通过读取当前激活项的 offsetTop 与 offsetHeight 计算， 确保在字体加载完成、窗口尺寸变化后依然精准对齐。

弹跳动画

位移量决定弧度：代码取 min(0.8, 14 / 距离) 作为弧线强度。 相邻菜单项之间距离小、弧度明显；跨分组长距离移动时弧度被压平，避免轨迹夸张。

方向也随之变化——向下移动时逆时针，向上移动时顺时针， 所以来回切换时圆点会走出相互对称的两条弧线。整个过渡时长 0.25 秒，缓出曲线。

高 DPI 适配
按 devicePixelRatio 取整计算尺寸与坐标，避免在 2x 屏上出现半像素模糊。
字体就绪对齐
监听 document.fonts.ready 后重新吸附一次，解决字体加载导致的行高跳动。
受控与非受控
传入 value 即为受控模式，否则内部自行维护选中态，两种方式都能触发 onChange。

分组与选中态

分组标题使用 role="presentation" 不参与交互，仅作视觉分隔； 标题文本沿用圆点的主题色，与指示器形成呼应。

选中项以文字颜色深浅区分：未选中为半透明色，选中后恢复为正文色并略微加重字重， 在深色背景下既克制又清晰。

使用方式

传入 items 数组即可渲染，配合 dotColor 自定义指示器颜色。 菜单项支持 href 时渲染为链接，未提供时渲染为按钮，两种形态共享同一套选中逻辑。

实现说明

本页为 React 组件的原生复刻版，使用纯 HTML / CSS / JavaScript 实现， 不依赖任何框架或动画库。圆点动画通过 requestAnimationFrame 逐帧插值完成， 弧线使用二次贝塞尔路径采样。
