弹跳侧边栏

一枚圆点指示器，在分组菜单之间沿弧线弹跳滑行。 切换选中项时它不会直线平移——向下走逆时针、向上走顺时针， 跨度越大弧线越平缓，于是来回切换会画出两条相互对称的轨迹。

◉ 试试点击左侧菜单的任意一项，留意圆点的行进路线。
01

组件构成

整个组件由三部分组成：分组标题、可点击菜单项， 以及一枚绝对定位的圆点指示器。菜单数据以数组描述， 每一项可以是纯字符串、带链接的对象，或标记为分组标题的对象。

圆点的纵向位置通过读取当前激活项的 offsetTop 与 offsetHeight 实时计算，因此在字体加载完成、窗口尺寸变化之后， 它依然能精准对齐到目标菜单项的中心。

指示器尺寸6px按 devicePixelRatio 取整
过渡时长250ms缓出曲线 easeOut
弧线强度min(0.8, 14/d)d 为纵向位移距离
02

弹跳动画原理

位移量决定弧度：代码取 min(0.8, 14 / 距离) 作为弧线强度。 相邻菜单项之间距离小、弧度明显；跨分组长距离移动时弧度被自动压平， 避免轨迹夸张失控。

方向也随之变化——向下移动时逆时针，向上移动时顺时针， 所以一来一回，圆点会走出两条彼此对称的弧线。

▦
高 DPI 适配
按 devicePixelRatio 取整计算尺寸与坐标，避免在 2x 屏上出现半像素模糊。
⌁
字体就绪对齐
监听 document.fonts.ready 后重新吸附一次，解决字体加载导致的行高跳动。
⇄
受控与非受控
传入 value 即为受控模式，否则内部自行维护选中态，两种方式都能触发 onChange。
bounce-sidebar.tsx 
// 距离越短弧度越明显，上限 0.8
const distance = Math.abs(delta);
const path = arc({
  strength: Math.min(0.8, 14 / distance),
  direction: delta > 0 ? "ccw" : "cw",
});
03

分组与选中态

分组标题使用 role="presentation" 不参与交互，仅作视觉分隔； 标题文本沿用圆点的主题色，与指示器形成视觉呼应。

选中项以文字深浅 + 左侧渐变底 + 内描边三重手段区分： 未选中为半透明灰，选中后恢复正文色、加重字重，并浮现右侧箭头。 在深色背景下既克制又足够清晰。

04

使用方式

传入 items 数组即可渲染，配合 dotColor 自定义指示器颜色。 菜单项若提供 href 则渲染为链接，否则渲染为按钮， 两种形态共享同一套选中逻辑。

用法示例 
<BounceSidebar
  dotColor="#f59e0b"
  items={[
    { label: "导航", heading: true },
    { label: "组件构成", href: "#overview" },
    { label: "弹跳动画原理", href: "#bounce" },
  ]}
/>
05

实现说明

本页是该 React 组件的原生复刻版，使用纯 HTML / CSS / JavaScript 实现， 不依赖任何框架或动画库。圆点动画通过 requestAnimationFrame 逐帧插值完成， 弧线使用二次贝塞尔路径采样，横向偏移峰值出现在行程中点。
